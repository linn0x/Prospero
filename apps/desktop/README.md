# Prospero Windows Desktop

Electron + React 实现的 Windows 11 Agent 工作台。直接连接 Prospero 现有 daemon，与 macOS 客户端共用协议、状态和会话实现。

## 安全与体积边界

- Renderer 开启 sandbox 与 context isolation，关闭 Node integration 和页面网络访问；
- control token 只由 Electron main 读取，通过白名单 IPC 暴露具体动作；
- 不加载远程页面，不允许新窗口、导航、设备权限或任意文件读取；
- 安装包仅携带一份 daemon 构建产物和 Node sidecar，不复制 daemon 业务实现；
- Electron ASAR 保持封装，仅解包必要的原生模块；xterm WebGL 不可用时自动回退 Canvas。

## 完整访问权限

设置页可选择通过 Windows UAC 以管理员身份启动本机托管的 daemon。开启或关闭时，正在运行的托管 daemon 会优雅重启；之后创建的 Agent 与 Windows Session Host 会继承对应权限。该设置默认关闭，外部启动的 daemon 不会被桌面端擅自提权或重启。

管理员 daemon 仍只接受带控制令牌的回环控制请求。桌面端使用这一通道执行优雅停止，因此不需要从普通权限进程强杀管理员进程。

## 会话阅读与每轮结果

深浅主题使用中性底色，正文、按钮和 diff 使用配套前景色。用户消息与助手答复均支持 Markdown 标题、列表、表格、代码高亮和数学公式。

每轮执行有独立的「查看过程」胶囊，运行时默认展开，完成后自动收起；主视图保留最终答复、成果文件与本轮改动。展开过程可以查看中间说明、思考摘要和工具记录，审批、待回答问题和失败信息保持可见。成果文件从最终答复的 Markdown 文件链接提取，点击后在右侧预览；diff 使用本轮快照，不把待审批的修改计入成果。左侧刻度按对话区域垂直居中，可点击或用方向键跳转到对应轮次。

运行 `npm run check:chat -w @prospero/desktop` 可在临时项目中验证真实 Electron 会话、每轮折叠、Markdown、成果预览、深浅主题文字对比度和窄窗口布局，截图与结果保存到 `output/desktop-chat/`。

## 项目文件与 Git 工具

文件、搜索和 Git 集成在会话右侧工作区中。左右工具栏顶部对齐，文件与终端共用一行标签；默认按窗口宽度分配空间，也可拖动细分隔线调整，按 Escape 取消拖动。点击右上角收起；窄窗口使用右侧抽屉。没有 Agent 会话时，也可在工作区顶部选择本地项目使用这些工具，无需启动 daemon。

主会话标签随数量增加自动收窄，到最小宽度后可用滚轮、触控板、左右按钮或「所有标签」菜单浏览。主会话与右侧工具栏均支持拖拽排序、边缘自动滚动和 Escape 取消；右侧文件、终端和工具可交叉排列，排序不重建编辑器或终端。会话顺序及各会话的工具顺序保存在本机。标签获得焦点时，方向键切换，`Ctrl+Shift+←/→`（macOS 为 `⌘⇧←/→`）调整位置。标签区域与窗口拖动区域分开，保留 macOS 的原生横向触控板滚动。

工作区与置顶会话采用单行标题，与目录行统一为 28px 高度，状态点固定在卡片最右侧内边距，置顶按钮位于状态点左侧；会话标题栏同样省略状态文字。完成为绿色，终止为红色，需要授权为蓝色闪烁，运行时呼吸缩放，完成未读时持续跳动。后台运行转为完成时自动标记未读，打开会话后清除。状态点保留辅助阅读标签与悬浮说明，系统减少动画时使用静态状态点。

macOS 的主会话标签、通用选项卡和分段选项使用液态玻璃材质与指针高光；会话区右侧工具栏的标签和分段选项保持普通样式。材质仅改变装饰，不影响标签宽度、拖拽或点击区域；减少透明度、提高对比度时自动回退。

- 文件管理：按需展开目录；新建文件/文件夹；通过右键菜单重命名、复制路径、移入系统回收站。
- 文件预览：宽面板内左侧预览、右侧文件树，工具栏可切换文件树；窄面板用「返回文件／搜索结果／变更」回到列表。支持多标签、代码高亮、行号、自动换行、Markdown 和常见图片预览；文本可编辑，使用 `Ctrl+S`（macOS 为 `⌘S`）保存。收起面板、切换工具或切换项目保留文件树、搜索条件、提交说明和编辑草稿。
- 文件栏：按文件类型显示图标，筛选框过滤已浏览目录中的文件名；文件夹仍可继续展开浏览匹配内容，清除筛选会保留原来的展开状态。
- 工作区终端：切换标签、收起工具区、切换宽屏分栏与窄屏抽屉时保留同一终端实例；隐藏期间不发送零尺寸调整，也不抢占输入焦点。抽屉收起动画保留内容，并遵循系统减少动画设置。
- 全局搜索：`Ctrl+Shift+F`（macOS 为 `⌘⇧F`）搜索当前所选项目的文本内容；支持大小写、全字匹配、文件路径包含筛选，点击结果定位到行。Git 项目遵循忽略规则，跳过依赖、构建产物、二进制及大文件；最多返回 500 条结果，并明确提示截断。
- Git 管理：当前分支及领先/落后数量、工作区/暂存区差异、单文件/批量暂存和取消暂存、提交已暂存内容、最近 30 条提交。支持尚未有首个提交的仓库。子目录项目需打开仓库根目录后使用 Git 功能。

文件访问仅限已添加项目及本地会话的项目目录。文件操作复用 daemon 的路径校验与读取实现；Git 命令复用同一执行层。超过 1 MB 的文件只读预览，保存前检查文件内容版本，遇到外部修改会保留编辑内容并报告冲突。关闭有修改的文件标签或退出应用前会提示未保存内容。

可运行 `npm run check:project-tools -w @prospero/desktop`，使用临时示例仓库检查真实 Electron IPC 与界面流程，截图和结果写入 `output/desktop-project-tools/`。该检查覆盖右侧布局与会话保留、收起/抽屉/跨项目切换后的草稿保留，以及预览、保存、搜索、Git 暂存提交、新建文件、图片和主题；同时验证会话状态点、后台完成未读、标签排序与 macOS 材质的渲染器规则及辅助功能降级。macOS 原生窗口材质仍需在 Mac 上实机确认。

## 开发命令

```powershell
npm install
npm run build -w @prospero/daemon
npm run dev:desktop
```

## 自包含安装包

```powershell
npm run package:windows -- -Architecture x64
```

产物位于 `dist/desktop`。安装后不要求用户另装 Node.js 或手动启动 daemon。
