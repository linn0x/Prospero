# Prospero Mobile

Expo SDK 57 / React Native 客户端，iOS 与 Android 共用同一套路由、协议和 UI。

会话页面与导航共用应用主题：背景、正文、输入框、快捷操作、代码、公式及弹层都随「浅色／深色／跟随系统」同步更新。切换主题通过 React 上下文更新颜色，不重建会话，保留草稿、展开状态和消息订阅。

## 分类设置

设置首页只保留分类入口和简短摘要：外观（主题、对话字体、最近对话数量、设备切换震动）、通知（持续通知、悬浮窗）以及设备管理（配对、设备排序和连接设置）。原「首页与交互」入口合并到外观，旧链接自动跳转。每个分类使用独立页面和原生返回导航；修改立即应用并保存，快速切换分类时会等待最新设置写入完成。Android 悬浮窗授权返回后仍会同步权限状态；其他平台会说明当前不支持的通知选项。

对话详情的更多菜单与「设置 → 外观」共用对话字号控制，支持 12–22、默认 15，以及恢复默认和即时预览。偏好在本机保存并应用到全部对话；正文、推理、代码、表格、公式、选择复制和输入文字按比例调整字号及行距，同时保留系统无障碍文字缩放。终端沿用原来的独立字号控制。

会话页右上角的展开／收起按钮同时控制标题下方的对话、模型、审批和搜索工具栏，以及输入框上方的快捷指令栏；选择保存在本机，隐藏时关闭正在进行的搜索。标题与右侧按钮分配独立空间，停止按钮保留占位，任务状态变化不会挤动标题。折叠屏双栏布局仍避开铰链。Codex 会话按每轮问答展示独立的「执行过程」胶囊：运行时展开，结束后自动收起，保留最终答复、「文件产出」以及本轮改动摘要。文件产出汇总答复引用的项目内文件。展开后可查看服务端提供的思考摘要、过程消息和工具记录；各轮的展开状态独立，滚出屏幕再返回不会丢失。待审批、待回答和失败状态保持可见，搜索仍可命中收起的过程。

「设置 → 快捷指令」可以分别编辑空闲和运行中的常用回复，每行一条，点击保存后应用到全部会话并在重启后保留。空组不显示快捷指令栏，恢复默认需要再次保存；写入失败时显示错误并保留编辑内容供重试。

## 远程终端

远程终端暂时仅支持 macOS。首页右上角的终端图标和设备页工具菜单只为 Mac 显示，Edge 模式仅列出已选的 Mac；设备类型未确认时不能新建。可返回已有 Shell 会话，或选定起始目录新建终端；留空使用电脑用户的主目录。使用电脑配置的登录 Shell（默认 zsh），通过现有加密连接和 PTY 执行交互命令；设备需已获 Shell 权限。

终端内置 JetBrains Mono Nerd Font Mono，图标按等宽单元格显示，不依赖 Android 系统字体或联网下载。首次布局等待字体就绪后再计算行列，避免文字与终端网格错位。字体与网页资源可以通过 Expo 热更新。

终端提供两行可横向滚动的按键栏，包括 Ctrl、Opt ⌥、Esc、Tab、方向键、Home/End、翻页、删除、粘贴和字号控制。Ctrl / Option 是单次组合键，可配合字母托盘或终端内的手机键盘；Option 加左右方向键按词移动，Option 加退格删词。点击粘贴保持原始内容。离开会话、进入后台或断线时清除组合键；断线时禁止发送或排队终端输入，重连不会重放旧命令。返回终端列表会保留 Shell；标题栏和列表的关闭按钮会终止终端，并等待电脑确认结束，断线、错误或超时保留错误提示。Ctrl+C 仅用于中断当前命令。终端结束后停止订阅，禁用所有输入。

Codex 的最终答复标记和完整轮次 diff 需要电脑端同步更新 daemon 并重启服务；旧记录按原有结束事件识别最终答复。改动摘要优先采用 Codex 原生轮次 diff，并可按文件展开补丁；不会把拒绝或失败的工具改动算作成果。文件产出沿用项目内文件预览，支持 Windows、macOS 和 Linux 路径。

## 文件查看与编辑

从对话引用或文件列表打开 Markdown 文件时，默认展示排版预览，可切换到源码；文件列表入口还可切换编辑，预览直接使用当前草稿，切换不会重置内容或自动保存。预览支持标题、列表、表格、公式、代码块和图片，项目内相对图片及文件链接以当前文档所在目录为基准解析。

常见代码文件默认使用彩虹色语法高亮，并按括号嵌套层级配色，支持明暗主题和一键关闭。对话及 Markdown 预览中的代码块也使用相同高亮。超过 8 万字符的内容使用原文模式以保持流畅；文件列表原有的 1 MB 读取截断仍保持只读并禁用保存。

## Prospero⁺ / Edge 模式

点击或长按首页左上角的 Prospero 标题，在普通首页与 Edge 首页之间切换。Edge 标题带有 `+` 和短暂动画，设备卡片展开显示全部配对设备的系统图标、名称和延迟；系统开启减少动态效果时跳过动画。

首次进入默认连接全部配对设备。设备区域使用紧凑网格，直接点击设备块选择或取消选择，高亮表示已选；长按查看设备详情。卡片内提供全选／清空，选择立即生效并自动保存；再次进入或重启 App 会恢复模式和设备范围。未作选择前，新配对设备自动加入；保存过选择后，新设备需要手动勾选。清空选择会显示选择设备的空状态，移除已选设备也不会自动扩大范围。

右上角 Agent 编排入口在两种模式下均可使用。Edge 只选一台设备时直接进入该设备编排；选择多台时，首页设备区域切换为目标选择，点选一台已选设备进入其编排，可点「取消」恢复设备勾选。未选设备时提示先选择设备，不会跳到其他设备。

所选设备的待审批、最近对话和工作目录显示在同一个列表中。最近对话按全局最近打开／活动时间排序，再应用设置中的数量限制；同名目录按来源设备分别显示。离线设备可显示本次 App 运行期间已有的缓存，不阻塞其他设备。点击对话进入其所属设备，展开目录可查看会话，左滑目录可新建对话或修改显示名称。「新对话」与「新建目录」分别位于最近对话、工作目录标题右侧；只有一台已连接设备时直接使用，多台时再选择目标。

两种首页的工作目录均以目录名为标题，确认存在 Git 仓库时，在目录名后显示一个小 Git 图标，不显示分支名或胶囊；会话数量独立放在右侧并垂直居中，与展开箭头对齐。下方小字显示原始路径和文件大小。保留设备的路径分隔符，长路径在中间省略，展开／收起时保持一致。非 Git 目录不显示图标。大小需要设备端支持 `workspace.summary.v1`；旧 daemon 通过分支信息识别仓库，未知大小不显示。目录扫描排除符号链接／junction，合并重复硬链接，限制扫描时间与条目数，未完成时显示 `≥` 下限；两端缓存一分钟，后台或离开首页后停止轮询。未读完成图标在离开首页或打开设备详情时停止并归零，返回后只对仍需提醒的会话恢复动画。

最近对话摘要在两种首页均仅显示一行。普通和 Edge 首页分别记录各设备各目录的展开状态，支持多个目录同时展开。Edge 目录的设备名与目录名同行显示，长名称省略，避免单独占用底部一行。工作目录按内容实际高度平滑展开和收起，文件夹始终使用同一个不透明图标，轻微旋转表达展开状态，箭头同步旋转，避免关闭时交叉淡化产生闪烁；设备页也使用相同的文件夹图标。收起过程中禁用隐藏会话的点击和辅助功能访问，动画结束后卸载内容。系统开启减少动态效果时直接切换状态。

取消选择会关闭该设备的首页连接；主动打开设备详情或深链仍可以连接该设备，返回 Edge 首页后重新应用选择范围。普通模式沿用原有设备切换与连接行为。

## 设备详情与新增设备

「设置 → 设备管理 → 设备排序」提供带系统图标和设备名的排序列表。拖动右侧把手，其他设备会让出位置，松手自动保存；拖到列表边缘可继续滚动，辅助功能也支持逐项上移／下移。顺序同步到普通首页、快速切换胶囊、Edge 设备列表和详情轮播，保留当前选中的设备；重启后恢复，新配对设备追加到末尾。顺序单独保存为设备 ID 列表，设备名称、连接信息及配对凭据不受排序影响。退出排序页或进入后台会取消尚未完成的拖动。

「设置 → 设备管理 → 目录排序」可选择设备并拖拽排列工作目录，松手自动保存，重启后恢复；顺序应用到普通首页、Edge 首页和设备会话列表。同名目录按设备分别保存，新目录追加到已排序目录之后。目录与设备共用排序手势，每行始终绑定同一个原生动画值，并使用窗口手势坐标，避免 Android 拖动时动画节点切换和位置跳动。

点击首页小卡片下方的胶囊打开详情轮播；只有一台设备时也可使用。第一台左侧、最后一台右侧各有一张新增设备页，两端小字提示也可点击。滑到新增页时，系统图标滑轨保持无选中状态，首页同步显示新增设备小卡片；切回真实设备或关闭详情后恢复。首页长按胶囊的快速切换只浏览已配对设备，不显示新增小卡片。详情靠上展示，左侧标题和描述直接位于遮罩上，右侧为独立圆形关闭按钮；短窗口下卡片内容可滚动，关闭按钮和滑轨保持可达。退出时立即移除遮罩并复位首页卡片，离开页面或进入后台时取消未完成的切换手势，返回后不会保留缩放或遮罩。

首页小设备卡片切换时保留平移和轻微缩放，卡片始终不透明，落位时不再淡入。胶囊状态点按卡片的连续位置在 5–7 dp 之间缩放，详情轨道的图标及背景高亮按同一滑动进度渐变；新增设备页不高亮任何已配对设备。切换设备时保留首页列表和胶囊组件，仅重置列表滚动位置，避免重建动画节点。

新增页提供扫码和「IP + 配对码」。手动方式使用电脑端 `prosperod pair` 生成的完整 `prospero://pair?d=…` 配对码；可填 IPv4/IPv6 地址及可选端口，也可留空沿用配对码地址。地址覆盖保留原设备身份和配对凭据。手动方式不会启动相机或请求相机权限；现有扫码、深链和粘贴完整配对串仍可使用。

## Android 构建与侧载

准备 JDK 17+、Android SDK 与 `platform-tools`，在仓库根目录安装依赖后运行：

```bash
npm install
npm run build:android -w @prospero/mobile
```

脚本会用 Expo CNG 重新生成 `android/`，安装 SDK 36 / Build Tools 36（缺少时），构建并校验一个可离线启动的 release APK。默认产物是：

```text
apps/mobile/build/apk/prospero-release.apk
```

直接装到唯一一台已连接、已授权的 adb 设备并启动：

```bash
npm run build:android -w @prospero/mobile -- --install --launch
```

有多台设备时追加 `--device <adb-serial>`。开发中已生成过原生工程时可用 `--no-prebuild` 缩短构建；更改 `app.json`、config plugin 或原生依赖后不要跳过 prebuild。

release APK 使用 Expo/React Native 模板随工程生成的 debug keystore 签名，只用于个人侧载。正式分发应在 CI 或 Gradle 中注入独立 release key，不要把密码或私钥写进脚本。

## ntfy 审批通知

Prospero 不直接接收 Android 推送；外部 ntfy App 显示通知，点击后通过 `prospero://` 深链回到对应主机与会话。因此 Android 13+ 的通知运行时权限要授予 **ntfy**，Prospero 自身不申请 `POST_NOTIFICATIONS`。

1. 按 [ntfy 官方 Android 指南](https://docs.ntfy.sh/subscribe/phone/)从 Google Play 或 F-Droid 安装 ntfy，并允许其发送通知。
2. 在 ntfy 中订阅一个难以猜测的 topic。自建服务器或不使用 Google 服务时，建议用 F-Droid 版；它用前台服务保持即时连接。
3. 在 Mac 上保存端点并发一条测试通知：

   ```bash
   prosperod notify --url https://ntfy.sh/<难以猜测的-topic>
   prosperod notify --test
   ```

4. 将 Prospero 切到后台，让 agent 触发审批；通知应到达，点击应打开具体会话。若 ROM 有激进省电策略，请允许 ntfy 后台运行；Prospero 本身被杀后会在深链唤起时重连。

公用 topic 名不是秘密存储且可能被猜中；审批详情虽只含会话名、动作和资源摘要，长期使用仍建议自建 ntfy 或至少使用高熵 topic。

## 开发与检查

```bash
# Android 模拟器/设备上的开发构建
npm run android -w @prospero/mobile

# 类型与移动端测试
npx tsc --noEmit -p apps/mobile/tsconfig.json
npm test -w @prospero/mobile
```

终端 HTML 由 daemon 侧唯一源生成。升级 xterm 依赖或修改 `apps/daemon/term.html` 后运行：

```bash
npm run build:terminal -w @prospero/mobile
```
